# 10 — Backlog y roadmap

## Fase 0 — Base técnica

- crear Laravel;
- configurar DB/env;
- instalar Livewire;
- autenticación;
- layout base y tokens visuales;
- Pest;
- CI básico si el tiempo lo permite.

**Salida:** proyecto arranca, usuario entra y pruebas base pasan.

## Fase 1 — Core multiempresa + módulos

- companies;
- memberships;
- roles/permisos mínimos;
- CompanyContext;
- modules/company_modules;
- onboarding;
- auditoría;
- tests de aislamiento.

**Salida:** empresa creada y módulos seleccionables.

## Fase 2 — Finanzas esenciales

Orden recomendado:

1. items/clientes;
2. Sales;
3. CxC;
4. Cash;
5. Inventory;
6. Suppliers/Purchases;
7. CxP;
8. dashboard.

**Salida:** flujos financieros del MVP completos con tests.

## Fase 3 — Indicadores y diagnóstico determinístico

- indicator definitions;
- snapshots;
- diagnostic rules;
- cards de alertas;
- seed de escenario 35% cartera vencida.

**Salida:** sistema identifica debilidad sin IA.

## Fase 4 — Educación y fuentes

- source documents;
- source chunks;
- cursos/unidades/clases;
- tareas/exámenes;
- progreso;
- 3 rutas iniciales curadas.

**Salida:** usuario puede estudiar de principio a fin sin IA.

## Fase 5 — Gamificación

- XP;
- nivel;
- racha;
- logros;
- retos y usuario-reto.

**Salida:** progreso motivador y medible.

## Fase 6 — IA mantenible

- AiProvider + adapter;
- PromptTemplate;
- Execution log;
- WeaknessExplainer;
- Recommender;
- SourceRetriever;
- GroundedTutor;
- ChallengeGenerator;
- QuizGenerator opcional si falta tiempo.

**Salida:** ciclo completo conectado.

## Fase 7 — Demo y endurecimiento

- seed determinístico;
- pulir UX;
- manejo de fallos IA;
- pruebas end-to-end manuales;
- datos de demo;
- script de presentación;
- performance básico;
- README instalación.
